# Digital Tańbaly — Таңбалы тас

Іле өзені бойындағы Таңбалы тас ескерткішіне арналған интерактивті 3D сайт.

- `site/` — сайттың бастапқы коды (`index.html`, `img/`)
- `Tanbaly-3D.html` — барлық суреттері ішінде бар бір файлдық нұсқа (`python3 site/build.py` арқылы жиналады)

Жергілікті ашу:

```bash
python3 -m http.server 8770
```

содан кейін http://localhost:8770/site/ ашыңыз.
